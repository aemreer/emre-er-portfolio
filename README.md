# Emre Er Portfolio

React ve JavaScript ile geliştirdiğim projeleri, kullandığım teknolojileri ve frontend alanındaki çalışmalarımı bir araya getiren kişisel web sitem.

## Kullanılan Teknolojiler

- React
- Vite
- JavaScript
- Tailwind CSS
- Framer Motion
- React Icons

## Özellikler

- Responsive tek sayfa tasarım
- Animasyonlu hero ve içerik geçişleri
- Etkileşimli yetenekler alanı
- Proje detayları, canlı demo ve GitHub bağlantıları
- Mobil menü
- İletişim alanı

## Kurulum

Projeyi yerel ortamda çalıştırmak için:

```bash
npm install
npm run dev
```

Production build oluşturmak için:

```bash
npm run build
```

Oluşturulan build dosyaları `dist` klasöründe yer alır.
